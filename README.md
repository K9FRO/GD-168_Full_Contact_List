# GD-168_Full_Contact_List
Worldwide DMR Contact List that will upload to the Radioddity GD-168 Radio

This list was built from the list available here:
[KF5IW Contact List](https://kf5iw.com/contactdb.php)

The original file was dated 9/21/26

I cleaned it in Excel:
- Removed non-ASCII characters
- Removed commas from within data fields
- Removed extraneous special characters, spaces, hypens, dashes, etc
- Removed State from all countries except for US, UK, Canada, Mexico, Australia
- Shortened Name field to max of 32 characters
- Etc

This file uploaded to the GD-168 radio using the Radioddity GD-168 CPS software where other files would always fail.
